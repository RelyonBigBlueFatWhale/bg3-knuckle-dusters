// 武器侧附伤 → 徒手通道 桥接被动（2026-10-18）
//
// 原理：BG3 有两套附伤通道
//     CharacterWeaponDamage(...)  角色侧，并入"武器伤害"掷骰
//     WeaponDamage(...)           武器侧 functor，靠武器伤害掷骰触发
// 指虎的攻击按徒手结算（这是本 mod 的设计，为了拿酒馆殴斗者与武艺），
// 徒手伤害里没有"武器伤害"这一项 ⇒ 上面两道通道都取不到值。
//
// 5eSpells 自己解决这个问题的方式是"同时写两条通道"，例如
//     CharacterWeaponDamage(1d6,Fire);CharacterUnarmedDamage(1d6,Fire)
// 但下列状态只写了武器侧，所以在指虎这类徒手攻击上一律静默失效。
// 这里给每一条补上等值的徒手通道；每行都带 HasStatus 判定，
// 只有该状态真的在身时才生效，因此不会与任何东西叠加。
//
// 逐条枚举依据：原版 Shared/Status_*.txt 与 5eSpells/Status_*.txt 里
// 所有 Boosts 含 WeaponDamage( 且没有 CharacterUnarmedDamage 的条目
// （AI_HELPER_* 是 AI 专用、OIL_OF_SHARPNESS_RANGED 是远程，均已排除）。
